## What's New

### New Languages

- **Go** — Added tree-sitter-based indexing for Go (`.go`). Extracts functions, methods, structs, interfaces, and type aliases.
- **Java** — Added tree-sitter-based indexing for Java (`.java`). Extracts classes, interfaces, enums, records, and methods. Class symbols are trimmed to their header when methods are present, keeping token usage compact.

### Token Efficiency

- **JS/TS class body trimming** — Classes with methods are trimmed to their header line, matching the treatment already applied to Python. Hono (TypeScript): **42× → 53×** token efficiency.
- **C++ class body trimming** — Classes and structs with inline methods are trimmed to their header line. LevelDB (C++): **34× → 418×** token efficiency.

### MCP Host Integration

- **Tool annotations** — All tools now set `readOnlyHint`, `destructiveHint`, and `openWorldHint`, enabling concurrent execution and removing unnecessary permission prompts in MCP clients.
- **Tool description rewrites** — Descriptions front-load "what and when" in the first sentence, staying within the ~2048 char truncation limits of MCP hosts.
- **Pagination** — `search_symbols` and `find_usages` now support `limit`/`offset` with truncation messages pointing to the next page.
- **Language filter fix** — `search_symbols` language filter now works correctly for all 8 indexed languages (was silently ignoring JS/TS/C/C++ in filter comparisons).
- **Structured error formatting** — Errors now return machine-readable codes with recovery hints (e.g. `PROJECT_NOT_INDEXED` → "Call index_project first").
- **`_meta` extensions** — `alwaysLoad` and `searchHint` fields added to tool definitions for MCP host discovery.
- **Progress reporting** — `index_project` emits progress notifications for large projects (>500 files).

### New Tools

- **`pitlane` CLI** — A standalone `pitlane` binary for running maintenance commands (e.g. `pitlane index <path>`) outside of an MCP session.

### Performance

- **`find_usages` early-exit** — File walk stops as soon as `offset + limit` usages are collected, skipping all remaining files when the page is already full.

### Correctness & Robustness

- **Cross-platform path normalization** — Symbol IDs and all `file` fields in JSON responses now always use forward slashes (`/`), fixing broken symbol lookups on Windows.
- **`find_usages` scope glob** — `scope` parameter validated and tested for JS, TS, C, and C++.
- **`index_project` file cap** — Configurable `max_files` guard prevents accidental full-filesystem walks (e.g. `index_project("/")`).

### Distribution

- **crates.io metadata** — `Cargo.toml` now includes `description`, `repository`, `readme`, `keywords`, `categories`, and `exclude` in preparation for publishing to crates.io.

## pitlane-mcp v0.7.0 - BM25 camelCase tokenizer and better indexing

### BM25 camelCase tokenizer

The BM25 index now uses a custom tokenizer that splits at camelCase, PascalCase, and digit boundaries before indexing. `LowerInstruction` is indexed as `["lower", "instruction"]`, `parseHTTPResponse` as `["parse", "http", "response"]`, `base64Encode` as `["base", "64", "encode"]`. Queries like `"lower instruction"` or `"http response"` now match symbols they previously missed entirely. This fixes BM25 quality on C++, Java, Swift, Kotlin, and C# codebases — languages where identifiers are almost exclusively camelCase or PascalCase.

The tokenizer is applied symmetrically at index time and query time, so existing indexes will be rebuilt automatically on first use after upgrading (the `.ready.v2` sentinel replaces the old `.ready` file).

### `get_project_outline` filtering and pagination

`get_project_outline` now accepts three new optional parameters:

- `path` — scope the outline to a subtree (e.g. `"kernel/sched"`)
- `max_dirs` — cap the number of directory entries returned (default 50, max 500); truncated responses include a hint
- `summary: true` — return only directory names with file and symbol counts, no per-file items or kind breakdowns; useful for very large codebases where the full outline exceeds context limits

### Semantic search (experimental)

`search_symbols` gains a `"semantic"` mode backed by locally-running embedding models via Ollama or LM Studio. Opt-in via `PITLANE_EMBED_URL` and `PITLANE_EMBED_MODEL` environment variables. See [SEMANTIC_SEARCH.md](https://github.com/eresende/pitlane-mcp/blob/main/SEMANTIC_SEARCH.md) for setup and model recommendations.

`index_project` emits live progress notifications during embedding generation for large projects (>500 files).

### `pitlane --version`

The `pitlane` CLI now supports `--version` / `-V`.

### Other

- `index_project` now always runs synchronously, removing a source of subtle race conditions on first-call indexing
- Various code clarity and formatting improvements

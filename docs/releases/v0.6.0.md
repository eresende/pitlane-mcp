## What's New

### New Tools

- **`get_lines`** — fetches a file slice by line range for blocks that aren't named symbols. Useful when an agent needs
context around a specific line without reading the whole file.
- **`get_index_stats`** — returns symbol counts by language and kind. Lets agents orient in a new codebase without burning
tokens on `get_project_outline`.

### Enhancements

- **`get_symbol` signature-only default** — when fetching a class, struct, interface, or trait symbol, only the header line
and docstring are returned by default (no method bodies). Pass `signature_only=false` to get the full body. Agents almost
always want the shape, not the implementation.
- **Usage statistics tracking** — `get_symbol` calls are now tracked internally (hit/miss counts, top queried symbols),
exposed via the new `pitlane stats` CLI subcommand.

### New Languages

- **PHP** — tree-sitter indexing for `.php` files. Extracts classes, interfaces, enums, methods, and functions. Class and interface bodies are trimmed to the header line when methods are present.
- **Zig** — tree-sitter indexing for `.zig` files. Extracts functions, methods, structs, enums, and consts.
- **Kotlin** — tree-sitter indexing for `.kt` and `.kts` files. Extracts classes, interfaces, enums, objects, functions, methods, and type aliases. Class and object bodies are trimmed to the header line when methods are present.
- **Lua / Luau** — tree-sitter indexing for `.lua` and `.luau` files. Extracts functions, methods, and type aliases. (thanks @CyanoTex)

### CLI

- **`pitlane stats` subcommand** — prints usage statistics for `get_symbol` calls (hit/miss counts, top queried symbols) without starting the MCP server.

### Benchmarks

Four new benchmark corpora, one per new language:

| Corpus | Language | Files | Symbols | Indexing (median) | Token efficiency |
|---|---|---|---|---|---|
| [Laravel v11.9.2](https://github.com/laravel/framework) | PHP | 2,331 | 26,127 | 156 ms | **80×** median |
| [zls 0.13.0](https://github.com/zigtools/zls) | Zig | 67 | 2,422 | 21 ms | **801×** median |
| [OkHttp 5.3.2](https://github.com/square/okhttp) | Kotlin | 644 | 6,780 | 59 ms | **54×** median |
| [Roact v1.4.4](https://github.com/Roblox/roact) | Lua | 95 | 93 | 4 ms | **90×** median |

pitlane-mcp now benchmarks across **sixteen** open-source corpora spanning **17 languages** (JavaScript and TypeScript share the Hono corpus).

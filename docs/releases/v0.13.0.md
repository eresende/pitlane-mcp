## pitlane-mcp v0.13.0 — safer BM25 queries and Tree-sitter 0.27

This release fixes BM25 searches containing apostrophes and upgrades the parser runtime to Tree-sitter 0.27.0.

Queries containing common contractions or possessives, such as `file's`, no longer fail during BM25 parsing. The query escaping layer now handles single quotes alongside the existing special characters, with regression coverage for apostrophes, double quotes, and plain text.

### Tree-sitter 0.27

The Tree-sitter runtime moves from 0.26.13 to 0.27.0. The Objective-C selector extraction code has been updated for the new child-index API types.

The upgrade was validated across all 19 language indexers and on Linux x86_64, Linux ARM64, macOS Apple Silicon, macOS x86_64, and Windows x86_64.

### BM25 query parsing

- Escape single quotes before passing user input to Tantivy's query parser.
- Preserve the fallback to the original query when escaped parsing fails.
- Add regression tests for apostrophe-containing queries and other escaped input.

### Other changes

- Updated blake3 from 1.8.6 to 1.8.7.
- Updated tree-sitter from 0.26.12 to 0.26.13 and then to 0.27.0.
- Updated transitive build dependencies associated with Tree-sitter 0.27.

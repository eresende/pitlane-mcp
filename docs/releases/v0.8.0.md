## pitlane-mcp v0.8.0 - graph-aware navigation, better indexing, and stronger Svelte support

### Graph-aware navigation

`find_callees` and `find_callers` are now available in the MCP server, giving pitlane shallow graph-aware navigation without changing its focused scope.

Use `find_callees` to inspect a symbol’s direct outgoing references, and `find_callers` to see direct incoming references for quick impact checks. This is meant to stay lightweight and fast: enough graph awareness to improve navigation, without turning pitlane into a heavier workflow or retrieval system.

The CLI now has matching `pitlane callees` and `pitlane callers` commands.

### Embedding progress and waiting

Embedding flows are easier to work with in this release.

A new `wait_for_embeddings` MCP tool blocks until embeddings finish, with live progress surfaced through the wait flow and index stats. On the CLI side, embedding generation is now synchronous, which makes behavior more predictable in scripts and manual runs.

This should make semantic search setup and first-run indexing much easier to reason about on larger projects.

### Faster and more robust usage search

`find_usages` now searches indexed files first before reparsing the wider tree. In practice, this reduces unnecessary work and improves performance on already indexed projects.

Indexing and watcher behavior were also tightened up. Changed-file handling is more robust, stale cache entries are invalidated when new source files appear, and watcher overflow now falls back to a full resync instead of silently drifting stale.

### Better Svelte support

This release expands Svelte support and fixes source-format and reference-handling issues. (Thanks @screenfluent )

`find_usages` now handles Svelte inline script column offsets correctly, and offset handling was cleaned up more broadly. Svelte benchmark coverage was also added to the docs and results.

### Search and indexing polish

A few smaller but useful improvements landed as well:

* exact `search_symbols` pagination is now deterministic
* thread-pool sizing and indexing internals were cleaned up and optimized
* localhost DNS issues in embedding-related CLI flows were fixed

### Docs and benchmarks

The README and benchmark docs were updated to reflect the expanded tool surface, new graph-aware navigation commands, Svelte coverage, and refreshed benchmark results.

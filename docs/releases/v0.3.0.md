## What's New

### New Languages

- **C and C++** — Added tree-sitter-based indexing for C (`.c`, `.h`) and C++ (`.cpp`, `.cc`, `.cxx`, `.hpp`, `.hxx`). Extracts functions, structs, enums, typedefs, and macros; C++ additionally covers classes, methods, and namespace-scoped symbols.
- **JavaScript and TypeScript** — Added indexing for JS/TS codebases. Covers function declarations, classes, arrow functions assigned to variables, exported variants, and TypeScript-specific constructs (interfaces, type aliases, enums, abstract classes). TSX supported via the dedicated grammar.

### Improvements & Fixes

- **`find_usages` JS/TS support** — AST-based usage search now covers JavaScript and TypeScript files (was silently returning empty results).
- **JS build output exclusion** — Common JS artifact directories (`dist`, `build`, `out`, `.next`, `.nuxt`, `.turbo`, etc.) are now excluded from indexing automatically.
- **Declaration file skipping** — TypeScript declaration files (`*.d.ts`, `*.d.mts`, `*.d.cts`) are excluded from indexing.

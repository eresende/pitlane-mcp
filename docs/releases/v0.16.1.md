## pitlane-mcp v0.16.1 — clearer embedding diagnostics, cleaner progress bars, and configurable bench runs

A small maintenance release on top of v0.16.0: the `doctor` embeddings check now tells you exactly which compatibility field mismatched instead of hiding behind matching format versions, the CLI progress bars no longer overlap log output, and the memory benchmark accepts a run count with JSON output. Dependency bumps (tantivy, chrono) and documentation for supported environment variables round it out.

### Fix: doctor reports all embedding compatibility fields (#128)

`EmbedStoreMetadata::is_compatible` compares four fields — format version, model, document fingerprint, and endpoint fingerprint — but `doctor` only reported the two format versions. After re-pointing an embedding endpoint or switching models, users saw `status: "incompatible"` with identical versions on both sides and no clue which field actually failed. The detail payload now carries all four store/current pairs (`store_model`/`current_model`, `store_document_fingerprint`/`current_document_fingerprint`, `store_endpoint_fingerprint`/`current_endpoint_fingerprint`), so the culprit is immediately visible. Covered by a new `test_incompatible_detail_reports_all_compared_fields` regression test.

### Fix: indexing progress without overlapping bars (#125)

Progress-bar output and log lines previously overwrote each other in the terminal. Log output is now routed above the progress bars so indexing progress stays readable.

### Bench: configurable memory_bench runs with JSON output (#126)

`memory_bench` accepts a configurable run count and emits JSON output, making memory measurements scriptable for tracking regressions across releases.

### Docs and dependencies

- Supported environment variables are now documented (#124), including a Muse Code MCP setup guide in QUICKSTART.
- `tantivy` 0.26.1 → 0.26.2 and `chrono` 0.4.44 → 0.4.45 via Dependabot (#122, #123).

### Validation

- Full CI suite green on all five release platforms (Linux x86_64/ARM64, macOS Apple Silicon/x86_64, Windows x86_64); Clippy and Rustfmt clean.
- All 6 `tools::doctor` tests pass, including the new incompatibility-detail regression test.
- Release binaries built from the `v0.16.1` tag by the release workflow; Homebrew formula updated automatically.

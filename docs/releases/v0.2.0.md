## What's New

### New Features

- **`get_symbol` signature_only parameter** — Retrieve just a symbol's API contract (signature) without the full implementation body, cutting token usage for API exploration workflows.
- **`find_usages` AST traversal** — Replaced brittle text search with tree-sitter AST traversal for accurate, language-aware usage lookups across the codebase.
- **Watcher debouncing** — File change events are now batched/debounced before triggering reindexing, reducing redundant work on rapid saves or bulk edits.
- **`.gitignore` awareness** — The indexer now respects `.gitignore` rules, skipping project-specific artifacts (build outputs, caches, etc.) automatically.

### Improvements & Fixes

- **Memory footprint** — Symbol file paths are now interned with `Arc<PathBuf>`, reducing heap allocations when the same file is referenced across many symbols.
- **Large file protection** — Files larger than 1 MiB are skipped during indexing to prevent memory exhaustion on generated or binary files.
- **Incremental index persistence** — The file watcher now persists index updates to disk after each batch, so the index survives process restarts without a full re-scan.

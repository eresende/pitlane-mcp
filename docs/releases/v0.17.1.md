## pitlane-mcp v0.17.1 — server diagnostics and faster CI

This release exposes server identity and startup diagnostics, sanitizes embedding configuration errors, and updates dependencies.

### Server identity and diagnostics (#136)

- MCP initialization reports the crate name and version.
- The default-tier `server_info` tool reports startup diagnostics with secrets excluded.
- Typed configuration error categories keep raw parser text out of logs and diagnostics.
- `doctor` reports one configuration result for disabled or invalid embedding settings.

### CI and release coverage (#142)

Regular CI runs on Linux x86_64, Linux ARM64, and macOS Apple Silicon. Windows x86_64 and Intel macOS build and test during releases. All five binary artifacts remain available. Release tests run before each platform's artifacts are uploaded, and manual releases build from the requested tag.

### Dependency updates (#133, #137–#140)

Clap 4.6.7, Tokio 1.53.2, libc 0.2.190, tree-sitter-swift 0.7.4, and tree-sitter-php 0.25.1.

### Validation

All six main CI checks passed after the dependency updates: Linux x86_64/ARM64 tests, Apple Silicon tests, Rustfmt, Clippy, and packaged-crate verification. Release-platform validation is pending.

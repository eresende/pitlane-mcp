# pitlane-mcp v0.9.1

This patch release focuses on making startup behavior more predictable, preventing semantic-search hangs, and improving the project documentation and demo material.

## Highlights

- `ensure_project_ready` is now non-blocking with respect to embeddings.
- Semantic `search_symbols` queries now have a timeout to avoid hanging on slow embedding backends.
- The CLI now reports total embeddings stored separately from the number newly written during the current run.
- The README includes a new demo video and visual comparison.
- A new quickstart guide explains installation, client setup, and recommended workflows.

## Behavior Changes

- `ensure_project_ready` now returns as soon as indexing is complete, even if embeddings are still running in the background.
- The `poll_interval_ms` and `timeout_secs` fields on `ensure_project_ready` remain accepted for compatibility, but they are ignored.
- The response now includes explicit embedding status guidance:
  - `running` means indexing is done, but semantic search is not yet ready.
  - `disabled` means non-semantic tools are ready immediately.
  - ready embeddings are reported as such without blocking startup.
- `search_symbols` in `semantic` mode now times out after 10 seconds by default.
- You can raise the semantic query timeout with `PITLANE_SEMANTIC_QUERY_TIMEOUT_MS` if your embedding backend is slow.

## CLI Improvements

- `pitlane index` now distinguishes between:
  - `embeddings_stored`: total vectors currently saved in the store
  - `embeddings_newly_stored`: vectors written by the current operation
- This makes it easier to tell whether the embeddings store already contained prior data.

## Documentation

- Added `QUICKSTART.md` with:
  - installation instructions
  - MCP client setup examples
  - a recommended tool hierarchy
  - prompt recipes for common tasks
  - guidance on avoiding broad searches
- Updated the README with a demo GIF and WebM comparison showing pitlane-mcp versus no MCP.

## Notes for Clients

- If you need semantic search readiness before continuing, call `wait_for_embeddings` explicitly after `ensure_project_ready`.
- If you do not need semantic search immediately, you can proceed with non-semantic tools right away.

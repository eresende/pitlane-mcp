## What's New

  ### New Languages

  - **Bash** — tree-sitter indexing for `.sh` and `.bash` files. Extracts functions.
  - **C#** — tree-sitter indexing for `.cs` files. Extracts classes, structs, interfaces, enums, methods, constructors,
  delegates, and type aliases. Class and struct bodies are trimmed to the header line when methods are present.
  - **Ruby** — tree-sitter indexing for `.rb` files. Extracts classes, modules, methods, and singleton methods. Class and
  module bodies are trimmed to the header line when methods are present.
  - **Swift** — tree-sitter indexing for `.swift` files. Extracts classes, structs, enums, protocols, functions, methods,
  inits, and type aliases. Extension methods are attributed to the extended type (`Foo (Bar)` methods appear as
  `Foo::method`). Class and struct bodies are trimmed to the header line when methods are present.
  - **Objective-C** — tree-sitter indexing for `.m` and `.mm` files. Extracts `@interface` classes (primary only; categories
  do not emit a duplicate type symbol), `@protocol` interfaces, method declarations and definitions, C-style functions, and
  typedefs. Multi-keyword selectors are preserved verbatim (`setName:age:`). Category methods are attributed to the extended
  class. NS_ENUM/NS_OPTIONS are skipped gracefully.

  | Corpus | Language | Files | Symbols | Indexing (min / median) | Peak RAM | Token efficiency |
  |---|---|---|---|---|---|---|
  | [bats-core v1.11.1](https://github.com/bats-core/bats-core) | Bash | 54 | 147 | 2 ms / 2 ms | 10.3 MB | N/A¹ |
  | [Newtonsoft.Json 13.0.3](https://github.com/JamesNK/Newtonsoft.Json) | C# | 933 | 7,284 | 84 ms / 86 ms | 76.7 MB | **65×** median |

  | [SDWebImage 5.19.0](https://github.com/SDWebImage/SDWebImage) | Objective-C | 271 | 1,564 | 15 ms / 16 ms | 29.0 MB | **54×** median |

  ¹ Bash has no struct/class symbols — only functions — so token efficiency does not apply.

  Hono corpus).
